# Profil individual — George Dinu

## Domenii de interes
- **Web development** (principal)
- **AI integrat în aplicații web** — sisteme care preiau input natural și returnează output structurat

## Ce vrea să învețe concret
- Să construiască un **API layer cu AI** care primește un prompt simplu de la un user non-tehnic și îl transformă într-un rezultat bine definit (task structurat, date extrase, acțiuni concrete)
- Aprofundarea logicii de server: baze de date, API design, procesare server-side

## Experiență anterioară
- Lucrează cu **Next.js** și **React**
- Confortabil cu full-stack web development
- Familiarizat cu conceptul de API-uri

## Idei de proiect motivante

### 1. Reminder inteligent
Userul scrie text liber ("trebuie să sun la doctor săptămâna asta") și sistemul extrage automat:
- task-ul concret
- deadline-ul
- prioritatea
- categoria
Totul programat și organizat fără input tehnic din partea userului.

### 2. Platformă de poze pentru evenimente
Site unde invitații de la un eveniment (nuntă, botez, petrecere) pot încărca pozele lor într-un loc centralizat, accesibil organizatorilor. Inspirat dintr-o nevoie reală observată.

## Rol preferat în echipă
- **Backend / logică de server** (prioritar)
- Frontend ca secundar — are experiența, dar vrea să crească mai mult pe server-side
- Interesat de rolul de **AI integration** în contextul backend
