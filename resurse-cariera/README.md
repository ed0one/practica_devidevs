## Cum le folosești

Sunt template-uri generaliste, un punct de plecare bun, nu forma finală. Deschide-le cu agentul (opencode), spune-i ce vrei diferit pentru tine, cere-i să le adapteze pe profilul tău. Fii autentic: pune ce ai făcut real, nu ce sună bine. Un angajator vede diferența.
